Pumice + Vite Task

Vite Task owns the graph and finite commands. Pumice owns worktree-scoped ports, service generations, readiness, leases, and cleanup.

Configuration

const pumice = definePumice({ ports: ['DATABASE_PORT'] })

tasks: {
  db: pumice.service({
    command: 'database --port $DATABASE_PORT',
    healthcheck: 'database-ready --port $DATABASE_PORT',
  }),
  'db:migrate': {
    command: 'pnpm db:migrate',
    dependsOn: ['db'],
  },
}

Process boundary

Vite Task

Task graph, finite commands, scheduling, cancellation, lease-holder lifetime.

Lease holder

Acquires one exact generation, reports readiness, and keeps its socket open.

Worktree daemon

Ports, slots, generations, definition hashes, readiness, and lease counts.

Service guard

Owns one foreground command and its complete process group.

Lifecycle

Absent → Starting(db-41) → Ready(db-41) → Stopping(db-41) → Absent
                  └──────→ Failed(db-41) ────────────────┘

Matching callers share generation 41. The final socket close stops it. A failed generation is never silently replaced for existing leases.

Failure guarantees

  • Lease-holder death releases exactly one reference.
  • Service death fails every holder for that generation.
  • Daemon death closes guard pipes and kills owned process groups.
  • Different canonical Git worktrees use different daemons and ports.
